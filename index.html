QuadCam Voices

Voice packs for EdgeTX radios. Listen to a pack here, then install it in QuadCam.

Install a pack

  1. In QuadCam, open Gear > Voices.
  2. Under Get voice packs, click Refresh packs.
  3. Click Install next to the pack. QuadCam checks the download's hash first.
  4. Click Apply to radios… to put the pack on a radio's card.
